# Nexa AI — Offline-first Local AI Assistant

Nexa AI runs chat and coding prompts through an AI model served locally by Ollama, llama.cpp, or another OpenAI-compatible server. No API key or internet is needed for local inference after the runtime, Python packages, and model are installed.

See the full setup guide in this README in the project source archive. Default: `NEXA_PROVIDER=local`, `http://127.0.0.1:11434/v1`, model `qwen2.5:3b`.

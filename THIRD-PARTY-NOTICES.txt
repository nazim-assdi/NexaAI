NexaAI is a Windows desktop application. The NexaAI installer includes the Ollama Windows runtime and Google Gemma 3 1B local model.

1. Ollama Windows standalone runtime
   Project: https://github.com/ollama/ollama
   Documentation: https://github.com/ollama/ollama/blob/main/docs/windows.mdx
   Bundled release asset: ollama-windows-amd64-rocm.zip from Ollama v0.40.18
   The Ollama runtime is embedded in the NexaAI installer under the application runtime folder.
   The upstream license is included as LICENSE alongside the bundled runtime.
   NexaAI starts Ollama as a local process and connects only to its app-specific loopback
   API at 127.0.0.1:11439.

2. Google Gemma 3 1B
   Model library: https://ollama.com/library/gemma3
   Model tag: gemma3:1b
   Approximate model download: 806 MB
   Terms: https://ai.google.dev/gemma/terms
   The model files are included in the NexaAI Windows installer and installed for the
   current Windows user. Gemma 3 1B is the sole chat and coding assistant model in this edition.

3. Python dependencies
   FastAPI, Uvicorn, Pydantic, HTTPX, Rich, python-multipart, python-dotenv, pypdf,
   NumPy, faster-whisper, CTranslate2, av, sounddevice, PortAudio, pyttsx3,
   comtypes and imageio-ffmpeg retain their respective upstream licenses.
   See each upstream project for license terms.

4. Whisper base speech-recognition model (downloaded on first Voice Chat use)
   Project: https://github.com/openai/whisper
   License: MIT (see upstream project/model distribution).
   This is a speech-to-text component for voice input, not another chat LLM.

5. imageio-ffmpeg
   Project: https://github.com/imageio/imageio-ffmpeg
   License: BSD 2-Clause.
   The Windows wheel includes an FFmpeg executable obtained from upstream builds.
   FFmpeg's own license depends on the options enabled in the binary; see
   https://ffmpeg.org/legal.html and the upstream build metadata.

6. Windows SAPI voices
   NexaAI uses Windows speech voices already installed by the user. No voice is
   redistributed by NexaAI.

7. Pillow
   Project: https://python-pillow.org/
   License: HPND. Used only in the Windows build pipeline to create multi-resolution
   application and installer icons; Pillow is not bundled with NexaAI.

NexaAI is an offline-first Windows desktop application and uses third-party software and a locally downloaded model.

1. Ollama (external prerequisite, not redistributed by NexaAI)
   Project: https://github.com/ollama/ollama
   Download: https://ollama.com/download/windows
   Ollama must be installed separately by the user. NexaAI connects to its local API at 127.0.0.1:11434.

2. Google Gemma 3 1B (downloaded by Ollama on first launch)
   Model library: https://ollama.com/library/gemma3
   Model tag: gemma3:1b
   Approximate download: 806 MB
   Terms: https://ai.google.dev/gemma/terms
   Gemma 3 1B is the single assistant model configured by this NexaAI edition.

3. Python dependencies
   FastAPI, Uvicorn, Pydantic, HTTPX, Rich, python-multipart, python-dotenv, pypdf,
   NumPy, faster-whisper, CTranslate2, av, sounddevice, PortAudio, pyttsx3,
   comtypes and imageio-ffmpeg retain their respective upstream licences.
   See each upstream project for licence terms.

4. Whisper base speech-recognition model (downloaded on first Voice Chat use)
   Project: https://github.com/openai/whisper
   Licence: MIT (see upstream project/model distribution).
   This is a speech-to-text component for voice input, not another chat LLM.

5. imageio-ffmpeg
   Project: https://github.com/imageio/imageio-ffmpeg
   License: BSD 2-Clause.
   The Windows wheel includes an FFmpeg executable obtained from upstream builds.
   FFmpeg's own licence depends on the options enabled in the binary; see
   https://ffmpeg.org/legal.html and the upstream build metadata.

6. Windows SAPI voices
   NexaAI uses Windows speech voices already installed by the user. No voice is
   redistributed by NexaAI.

7. Pillow
   Project: https://python-pillow.org/
   License: HPND. Used only in the Windows build pipeline to create multi-resolution
   application and installer icons; Pillow is not bundled with NexaAI.

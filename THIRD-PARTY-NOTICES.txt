NexaAI is a Windows desktop application. The NexaAI installer includes the Ollama Windows runtime. Qwen2.5-Coder model weights are downloaded from the Ollama model registry on first launch.

1. Ollama Windows standalone runtime
   Project: https://github.com/ollama/ollama
   Documentation: https://github.com/ollama/ollama/blob/main/docs/windows.mdx
   Bundled release asset: ollama-windows-amd64.zip from Ollama v0.11.10
   The Ollama runtime is embedded in the NexaAI installer under the application runtime folder.
   The upstream license is included as LICENSE alongside the bundled runtime.
   NexaAI starts Ollama as a local process and connects only to its app-specific loopback
   API at 127.0.0.1:11439.

2. Qwen2.5-Coder 1.5B
   Project: https://github.com/QwenLM/Qwen2.5-Coder
   Model library: https://ollama.com/library/qwen2.5-coder
   Ollama tag: qwen2.5-coder:1.5b
   Approximate download: 986 MB
   Model license: Apache License 2.0.
   License text is bundled with the NexaAI application. Model weights are downloaded
   automatically by the bundled Ollama runtime on first launch and stored under the
   current Windows user's NexaAI engine folder.

3. Google Gemini API (optional online service)
   Documentation: https://ai.google.dev/gemini-api/docs
   Models: Gemini 3.8 Flash (gemini-3.8-flash) and Gemini 3.1 Flash-Lite
   (gemini-3.1-flash-lite), subject to current Google AI Studio availability and
   free-tier limits. Gemini model weights are not redistributed by NexaAI.
   Users provide their own Google AI Studio API key. NexaAI stores it encrypted
   using Windows DPAPI for the current Windows user.

4. Python dependencies
   FastAPI, Uvicorn, Pydantic, HTTPX, Rich, python-multipart, python-dotenv, pypdf,
   NumPy, faster-whisper, CTranslate2, av, sounddevice, PortAudio, pyttsx3,
   comtypes and imageio-ffmpeg retain their respective upstream licenses.
   See each upstream project for license terms.

5. Whisper base speech-recognition model (downloaded on first Voice Chat use)
   Project: https://github.com/openai/whisper
   License: MIT (see upstream project/model distribution).
   This is a speech-to-text component for voice input, not another chat LLM.

6. imageio-ffmpeg
   Project: https://github.com/imageio/imageio-ffmpeg
   License: BSD 2-Clause.
   FFmpeg's own license depends on the options enabled in the binary; see
   https://ffmpeg.org/legal.html and the upstream build metadata.

7. Windows SAPI voices
   NexaAI uses Windows speech voices already installed by the user. No voice is
   redistributed by NexaAI.

8. Pillow
   Project: https://python-pillow.org/
   License: HPND. Used only in the Windows build pipeline to create application
   and installer icons; Pillow is not bundled with NexaAI.
